# Tools

> *"Every fortress needs its arsenal."*

This directory contains standalone tools and utilities built on Ironcreed principles. Each tool is self-contained and can be deployed independently.

## Available Tools

### [Sentinel](sentinel/)
File integrity monitoring system that watches for unauthorized changes to critical files.
- Hash-based verification
- Baseline snapshots
- Change detection
- Audit logging

## Using a Tool

Each tool has its own directory with:
- `README.md` - Documentation and usage instructions
- Source code
- Tests (where applicable)
- Configuration examples

Navigate to the specific tool directory for detailed information.

## Contributing a Tool

When adding a new tool:

1. Create a directory with a clear name
2. Add a comprehensive README
3. Follow defensive coding practices
4. Include error handling
5. Add tests where feasible
6. Document security considerations

See [CONTRIBUTING.md](../CONTRIBUTING.md) for guidelines.
